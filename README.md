Entry for the [Say What Actually Broke](https://make.fun/competitions/u-po-pu-say-what-actually-broke-a2c153b5) bounty on [make.fun](https://make.fun/?ref=ajkq5baq): a program that writes one line of software error copy — at most 200 characters — that tells the user the brutal truth about what broke and makes them laugh.

## Run

```sh
node main.ts
```

This writes the error line to `/output/entry.txt`.
